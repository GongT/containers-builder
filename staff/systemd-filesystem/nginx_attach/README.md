# nginx附加服务组件

输入参数:
* CONFIG_FILE - 配置文件（或目录）在容器中的路径，默认为 /opt/nginx.conf 或 /opt/nginx/

如果传入了 CONFIG_FILE，不会检查它是否存在，以允许运行时生成。


# 功能

添加一个自启动、无相互依赖的独立服务 nginx-attach.service ，以及一些其他工具。

启动时打包指定的 nginx 配置文件或目录，发送给网关服务器。

由于网关服务器不一定先于当前容器启动，所以它会反复重试直到成功为止（通过定时器）。容器自身的成功状态不会依赖nginx-attach.service。

容器退出时，还会通知网关服务器将配置删除。
